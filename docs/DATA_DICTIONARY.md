# 数据字典

一行代表一场竞彩足球受注比赛。时间统一保存为带时区的 ISO 8601，北京时间示例：`2026-09-04T03:00:00+08:00`。

| 字段 | 必填 | 说明 |
|---|---:|---|
| `match_id` | 是 | 稳定唯一编号，建议 `YYYYMMDD-竞彩编号` |
| `lottery_date` | 是 | 竞彩销售日期，不是自然开赛日期 |
| `match_no` | 是 | 官方编号，如 `周四006` |
| `competition` | 是 | 官方中文赛事简称 |
| `kickoff_time` | 是 | 带时区的实际开赛时间 |
| `home_team` / `away_team` | 是 | 官方受注名称，另建映射表处理别名 |
| `home_score` / `away_score` | 赛后 | 90分钟含补时结果，不含加时和点球 |
| `handicap` | 否 | 竞彩让球数，主队让球为负、受让为正 |
| `spf_*_odds` | 否 | 非让球胜平负固定奖金 |
| `rqspf_*_odds` | 否 | 让球胜平负固定奖金 |
| `source_url` | 强烈建议 | 原始数据网页，方便审计 |
| `collected_at` | 强烈建议 | 赔率或赛程采集时间 |

## 数据纪律

1. 不补造缺失赔率、伤停或比赛结果。
2. 每条数据保存来源与采集时间，赔率必须是时间切片，不能覆盖历史快照。
3. 预测特征只使用开赛前已经发生的数据，防止未来信息泄漏。
4. 延期、腰斩、取消、加时和点球应在后续事件表中单独记录。
5. 中文队名需要维护官方名、常用名和国际名映射，不能只靠模糊匹配。
