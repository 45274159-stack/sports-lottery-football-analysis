# 赛前数据采集

## 已接入

`sporttery collect-prematch` 按受注日期保存一份不可覆盖语义的 JSON 快照，包含：

- 竞彩足球固定奖金：胜平负、让球胜平负、比分、总进球、半全场；保留接口返回的每次更新时间和数值；
- 伤停/停赛：按主客队保存球员、位置、原因和状态；空列表只表示“数据源未列出缺阵”，不等于全员健康；
- 新赛季技术资料：比赛详情页公开的近期赛果、比赛特征、积分表和未来赛程原始证据；
- 数据血缘：每个接口的 URL、成功/失败状态、采集时间以及原始响应。

## 首发边界

当前没有验证到中国体彩网公开接口提供正式首发十一人。因此快照中的 `lineups.status`
固定为 `unavailable`，不会把预计阵容、射手资料或媒体名单冒充正式首发。后续接入有授权的
阵容供应商时，仍必须同时满足：11 名不同球员、官方/授权来源、发布时间早于开赛时间。

## 使用

```bash
sporttery collect-prematch \
  --date 2026-09-04 \
  --output data/raw/prematch/2026-09-04/210000Z.json
```

建议一天至少保存早盘和临场两份文件，不能用临场快照覆盖早盘。若网络被官方安全策略拒绝，
命令会停止并说明原因；不得绕过访问控制。原始快照默认不提交 Git，需另行备份到受控存储。

## 尚未接入

- 正式首发十一人：需要可靠且获授权的数据源；
- 事件级高级指标（xG、射门位置、压迫等）：体彩公开详情不保证完整提供；
- 跨供应商球队/球员 ID 映射：接入第二数据源前必须先建立别名和冲突审计。
