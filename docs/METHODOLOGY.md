# 分析方法

本项目把赔率定位为辅助信号，不把低赔率等同于“稳”。赛前报告依次检查：

1. 官方编号、球队、开赛时间与是否仍在售；
2. 最近比赛状态，并按对手强度、主客场和样本时间衰减；
3. 休息天数、连续客场、跨国旅行及多线赛程；
4. 伤停是否影响门将、中卫、中场组织者和主要得分点；
5. 联赛排名、保级/争冠、杯赛首回合比分和轮换动机；
6. 主客场进攻、防守和预期进球差异；
7. 最后才比较竞彩固定奖金隐含概率与独立估计。

当前 `analysis.py` 只是透明、可复现的 Poisson 基线，用于验证数据管道，不是成品推荐模型。后续需要加入联赛平均值、对手强度修正、阵容价值、休息天数、Elo、xG 和时间切片赔率，并用滚动时间窗口回测。

## 回测原则

- 训练集必须早于验证集；禁止随机打乱跨时间比赛。
- 同时报告准确率、Brier score、log loss、ROI、最大回撤和样本量。
- 以市场去水概率和“永远选热门”为基线。
- 按联赛、赔率区间、玩法和赛季分别评估，避免总体数字掩盖失效区域。
- 每次赛前观点和最终结果都留档，错误原因区分为信息缺失、模型误判和比赛随机性。
