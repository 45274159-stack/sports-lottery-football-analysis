# 已训练攻防模型 v1

这次交付的是可加载的拟合参数，而非只有注册表或固定均值规则。
算法为带L2正则和时间权重的独立泊松回归：
主队进球强度=exp(主场截距+主队攻击参数+客队防守参数)，客队同理。
每队有攻防两个已拟合参数，防守参数越高表示失球强度越大。
固定设置：365天半衰期、正则5、300次阻尼迭代；未根据本次测试分数调参。
优化采用阻尼对角Newton近似，尚未提供收敛最优性证明或置信区间。

## 两份模型文件

- `data/models/fitted_poisson_2024-06-30.json`：只用2024-06-30及之前的数据拟合，冻结参数后评估后续比赛。
- `data/models/fitted_poisson_2026-06-30.json`：使用截止2026-06-30可用历史重新拟合，供后续实验预测；这份最新参数还没有独立前瞻成绩。

每份包含五大联赛参数、训练场数、实际最近比赛日期、输入哈希、版本和限制。
这五个模型来自同一算法按联赛分别拟合，不是五种不同算法。

## 使用

```sh
PYTHONPATH=src python -m sports_lottery.fitted_model predict data/models/fitted_poisson_2026-06-30.json --league 'Premier League' --home Arsenal --away Chelsea --before 2026-09-05
```

此命令是加载烟雾测试用的假设对阵，不代表当天有该比赛，不是投注建议。
输出90分钟胜平负、前5比分、总进球0—6与7+及期望进球。
不接受训练截止日期之前预测；未见球队拒绝输出，不偷用平均球队代替。
它不自动核对真实赛程，也没有接入伤停、首发、射门质量xG或赔率。
训练期望进球不是事件级xG；独立泊松不能充分刻画红牌、比赛状态和进球相关性。
模型JSON通过专用命令加载；既有pipeline和模型注册表尚未自动切换到本模型。
已有模型库候选登记保持不变，不冒充正式启用。没有真实固定奖金和投注记录，不计算盈利率。
